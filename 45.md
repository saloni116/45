## Experiment 4: MongoDB NoSQL Commands
1. Open **MongoDB Compass**.
2. Connect using `mongodb://localhost:27017`.
3. Create database `BDA_Lab` and collection `students`.
4. Insert the documents using the code below in **Add Data → Insert Document** (insert each separately).
5. Use the Filter box to search, update and delete records.

### Code

Run these commands in **MongoDB Shell (`mongosh`)**, not in the Compass Filter box.
use BDA_Lab

db.students.insertMany([
  {rollno: 1, name: "Asha", marks: 85},
  {rollno: 2, name: "Riya", marks: 90},
  {rollno: 3, name: "Neha", marks: 78}
])

db.students.find()

db.students.find({marks: {$gt: 80}})

db.students.updateOne(
  {rollno: 1},
  {$set: {marks: 88}}
)

db.students.deleteOne({rollno: 3})

db.students.find()



## Experiment 5: Neo4j Nodes and Relationships

### Execution Process

1. Open **[Neo4j Aura](https://console.neo4j.io/)**.
2. Create or open your free database instance.
3. Open the Query editor.
4. Paste and run the code below.
5. View the graph in the results.

### Actual Code (Cypher)
CREATE (a:Person {name: 'Asha'})
CREATE (b:Person {name: 'Rani'})
CREATE (c:Person {name: 'Shinde'})
CREATE (a)-[:FRIENDS_WITH]->(b)
CREATE (b)-[:FRIENDS_WITH]->(c);
### Display the Graph

Run this separately:
MATCH (a:Person)-[r:FRIENDS_WITH]->(b:Person)
RETURN a, r, b;

**Expected output:** Three person nodes connected by two `FRIENDS_WITH` relationships.

**Important:** If you run the creation code again, it will create duplicate nodes. For your practical, execute it once and then run the display query.
